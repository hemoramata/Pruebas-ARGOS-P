# ADR-0043 - Estrategia de identificación de países

**Estado:** Aprobado

**Fecha:** 2026-07-28

**Versión objetivo:** ARGOS v1.0

**Normalización documental:** Renumerado como ADR-0043 el 3 de septiembre de 2026. El archivo anterior se llamaba `ADR-0001.md` y su encabezado indicaba ADR-0003, ambos identificadores ya utilizados en la bitácora fundacional BIT-0001. La renumeración evita la colisión sin cambiar la decisión aprobada.

---

## Contexto

ARGOS será utilizado inicialmente por organizaciones costarricenses, incluyendo
municipalidades e instituciones públicas que actualmente utilizan un catálogo propio
de códigos de países basado en la práctica institucional existente.

Aunque el estándar internacional para identificar países es ISO 3166-1 (Alpha-2,
Alpha-3 y Numérico), el mercado objetivo requiere compatibilidad con el catálogo
utilizado actualmente por dichas instituciones.

Durante el análisis de arquitectura se evaluó implementar desde la versión 1.0 el
soporte para múltiples estándares internacionales.

---

## Problema

Implementar desde la primera versión múltiples estándares de identificación de países
incrementaría considerablemente la complejidad del dominio:

- Configuración inicial del sistema.
- Catálogos múltiples.
- Estrategias de validación.
- Migraciones futuras.
- Mayor cantidad de pruebas.

Dicha complejidad no aporta valor inmediato para el mercado objetivo de la primera
versión del producto.

---

## Decisión

ARGOS v1.0 utilizará un único estándar de identificación de países compatible con
el catálogo requerido por las instituciones objetivo.

El Value Object `CountryCode` validará únicamente dicho catálogo.

No existirá configuración para seleccionar diferentes estándares durante la versión
1.0.

---

## Consecuencias

### Positivas

- Menor complejidad del dominio.
- Implementación más sencilla.
- Menor cantidad de código.
- Mayor velocidad de desarrollo.
- Compatibilidad inmediata con el mercado objetivo.
- Menor riesgo durante la primera liberación.

### Negativas

- No será posible cambiar de estándar sin una actualización del sistema.
- Integraciones internacionales requerirán adaptación.

---

## Decisión futura (ARGOS v2.0)

La versión 2.0 incorporará soporte para múltiples estándares de identificación de
países mediante configuración del sistema.

Se evaluarán los siguientes estándares:

- Catálogo Institucional (compatibilidad)
- ISO 3166-1 Alpha-2
- ISO 3166-1 Alpha-3

El estándar seleccionado será configurable durante la instalación inicial del ERP.

---

## Justificación

Se adopta el principio arquitectónico:

> "Construir primero una versión simple, estable y orientada al negocio antes de
> introducir flexibilidad arquitectónica."

Esta decisión permite entregar valor rápidamente sin comprometer la evolución futura
del sistema.

---

## Estado de implementación

✅ Aprobado para ARGOS v1.0

Pendiente para ARGOS v2.0:
- Configuración del estándar de países.
- Catálogo internacional.
- Estrategia de validación configurable.
- Migración de datos.
