# ADR-0052 - Consola web de administración institucional y técnica

**Estado:** Aprobado  
**Fecha:** 7 de septiembre de 2026  
**Versión objetivo:** ARGOS 3.0  
**Aprobación del propietario:** Confirmada el 7 de septiembre de 2026

## Contexto

ARGOS Desktop será el cliente operativo oficial inicial. Sin embargo, instalar una
herramienta administrativa completa en cada estación dificultaría la labor centralizada
de los departamentos de TI, especialmente cuando ARGOS opere con múltiples servidores.

El propietario aprueba que la administración del sistema sea web. Esta consola no debe
confundirse con el cliente web operativo para funcionarios previsto para una fase posterior.

## Decisión

ARGOS contará con una Consola Web de Administración accesible únicamente para personas
autorizadas. Podrá entregarse junto con la primera etapa Desktop y centralizará la
implantación, configuración y supervisión técnica e institucional.

La pantalla de configuración organizacional creada en esta entrega será el primer módulo
de esa consola.

## Alcance previsto

- primera implantación y parámetros generales;
- organigrama, Posiciones, Competencias y versiones organizacionales;
- Personas, identidades, Asignaciones y accesos, cuando esos módulos existan;
- políticas, jerarquías de aprobación y calendarios;
- inventario automático, salud y versión de nodos ARGOS Server;
- actualizaciones, compatibilidad, diagnósticos y auditoría administrativa;
- publicación de configuraciones y conocimiento institucional autorizado.

## Seguridad obligatoria

1. No estará expuesta públicamente a Internet por defecto.
2. El acceso se limitará a la red institucional, VPN o canal administrativo equivalente.
3. Exigirá autenticación reforzada y autorización por función; conocer la dirección web
   no concederá acceso.
4. Toda consulta sensible y toda modificación quedarán en la Auditoría técnica separada
   de la Trazabilidad funcional.
5. Las acciones críticas conservarán actor, Asignación, Posición, Competencia, política,
   autorización y hora del servidor cuando los módulos correspondientes estén disponibles.
6. La consola no accederá directamente a proveedor anterior o PostgreSQL; utilizará la API de ARGOS.
7. Un nodo descubierto automáticamente no podrá activarse sin completar el enrolamiento
   seguro definido en ADR-0050.

## Relación con los clientes

- **Desktop:** operación diaria de funcionarios y capacidades locales.
- **Administración Web:** configuración y supervisión central por TI y autoridades.
- **Web operativo:** canal posterior para perfiles funcionales autorizados.
- **Mobile:** canal posterior para funciones móviles específicas.

Todos utilizan contratos del mismo ARGOS Server y ninguno duplica reglas de negocio.

## Estado de implementación

El primer módulo visual de implantación y la API organizacional están implementados.
Autenticación, autorización real, auditoría administrativa, administración de nodos y
los demás módulos de la consola permanecen pendientes.
