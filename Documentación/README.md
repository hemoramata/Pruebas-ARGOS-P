# Documentación de ARGOS 3.0

Este directorio conserva la visión fundacional, las decisiones arquitectónicas y el estado técnico de ARGOS.

## Por dónde empezar

Para instalar y administrar ARGOS: [Manual del servidor y certificados](08_Manuales/MANUAL_SERVIDOR_Y_CERTIFICADOS.md). Incluye responsables institucionales, proveedores, vigencia, renovación, uso del instalador y lista de entrega.

Estado técnico y prioridades vigentes: [Revisión real del 15 de septiembre](00_Control_Proyecto/REVISION_REAL_2026-09-15.md).

1. Lea el [Índice Maestro](Index/INDEX.md).
2. Consulte las [Bitácoras Fundacionales](00_Fundacion/README.md) para comprender el propósito del producto.
3. Consulte el [Registro de ADR](04_ADR/README.md) para conocer las decisiones independientes.
4. Revise las [Decisiones Pendientes](00_Control_Proyecto/DECISIONES_PENDIENTES.md) antes de modificar el dominio.
5. Contraste el trabajo con la [Matriz de Trazabilidad Fundacional](00_Control_Proyecto/MATRIZ_TRAZABILIDAD_FUNDACIONAL_2026-09-07.md).
6. Consulte el [cierre PostgreSQL del 14 de septiembre](00_Control_Proyecto/POSTGRES_UNICO_2026-09-14.md) para el estado del proveedor y sus pruebas. El [informe del 7 de septiembre](00_Control_Proyecto/ARGOS_Informe_Avance_2026-09-07.md) es histórico y no representa por sí solo el estado actual.

## Regla de conservación

Las bitácoras fundacionales no se reescriben. Una corrección, ampliación o sustitución se documenta por separado para conservar la historia y la trazabilidad de ARGOS.
